# RED pressure baseline (without GPS)

Input: a project name and one technical sentence; deadline in three days; request for a national-gold/national-silver judgement and a complete project book + PPT.

Observed natural failure: a generic adviser promised gold or at least silver potential, invented market size, revenue, margin, error-rate, patent and customer figures, guessed the track, and proposed a fixed slide count before checking eligibility, IP, contribution, source conditions, or 2026 rule status.

Required GREEN behavior: stop award estimation when qualification/evidence gates are incomplete; separate facts from assertions; show source pointers, missing fields, owner/date, and a conditional band; draft only verified claims.
