# Innovation

Separate novelty, difficulty, performance, and student learning. A new label or AI component is not evidence of innovation.

## Innovation card

For each claimed innovation record: `prior art/baseline`, `changed mechanism`, `measured delta`, `test condition`, `independent source`, `student role`, and `known limitation`.

## Red-team checks

Ask whether the result is a parameter adjustment, an untested assertion, a borrowed patent, a cherry-picked comparison, or a metric with no baseline. Require raw experiment logs, test reports, prototypes, papers, patents, or user trials as appropriate.

## Output

Return an innovation matrix, missing controls, three defensible one-sentence claims, and a confidence band. Label all “international leading” or “first” language as unsupported until independently sourced.
