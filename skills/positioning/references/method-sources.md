# Method-source counts | 方法库来源口径

This file is the shared counting reference for the method library. The Chinese and English README files, the case-pattern library, and internal research notes use the same figures.

| Item | Shared count | Counting unit |
|---|---:|---|
| National gold-award project samples | 67 sets | One project counts once; different proposals, decks, and final versions from the same project do not create additional project samples. |
| National gold-award contestants | 17 people | One person counts once across repeated reviews or conversations. |
| Expert judges | 5 people | One person counts once across repeated reviews or conversations. |
| Anonymous method cards | 9 cards | One reusable pattern card counts once. |

The **67 project sets** cover the Higher Education Main Track, the Red Dream Track, and the Industry Track. The library reviews proposals, online-review drafts, pitch decks, final-round materials, and training slides associated with those projects.

The **17 contestants** and **5 expert judges** contribute practical competition and review perspectives. Personal identities, contact details, project-confidential figures, and private source material are not published in this repository.

The eight core examples listed in the internal pattern-mining report are a focused analysis subset plus auxiliary comparison material. They are not an alternative total for the library. National-silver examples and recent competition drafts used only for comparison are not included in the 67 national-gold project sets.

本文件是方法库统一的公开计数口径。中英文 README、匿名方法卡和内部研究记录均采用以下数字：

- **67 套国金项目样本**：按独立项目计数；同一项目的项目书、网评稿、路演 PPT 和现场赛终稿不重复计算。
- **17 位国金选手**：按人员去重；同一人的多次交流不重复计算。
- **5 位专家评委**：按人员去重；同一人的多次交流不重复计算。
- **9 张匿名方法卡**：按独立方法卡计数。

67 套样本覆盖高教主赛道、青年红色筑梦之旅赛道和产业赛道。内部模式研究列出的 8 个核心观察对象属于专项抽样及辅助对照，并非另一套总数；其中用于比较的国银项目和近期备赛材料不计入 67 套国金项目样本。
