# Slide patterns from historical winners

Use these as narrative patterns (`L4`) and adapt them to the current track and stage.

| Pattern | Job | Proof to show |
|---|---|---|
| Problem–fieldwork | Establish a real need | interview count, site/date, user quote, source |
| Pain–technical response | Make innovation legible | mechanism, baseline, metric, condition |
| Prototype–test–use | Close the credibility loop | sample/prototype, test record, pilot or acceptance |
| IP–team–growth | Show student ownership | filing/award source, contribution map, learning arc |
| Customer–economics | Make scale plausible | customer stage, pricing basis, unit economics, downside |
