# Proposal

A project book should let a reviewer follow the argument and check the important claims. Start with the argument map, then revise prose.

## Working spine

Adapt this pattern to the track and project maturity:

project snapshot -> context and need -> field research -> development path -> problem / intervention / metric -> product and use -> alternatives -> IP and results -> validation and adoption -> student contribution -> business model -> finance and risk -> social value -> plan.

This is a pattern learned from historical 国创赛, 大挑 and 小挑 materials. It is not a 2026 page limit or template.

## Maturity lanes

- Idea: establish the user, problem, field evidence and first test.
- Prototype: show the mechanism, baseline, test condition and failure cases.
- Pilot: show user acceptance, repeatability, delivery path and ownership.
- Revenue: separate paid transactions from forecasts, margins and scale assumptions.

Do not let a revenue-style section hide an untested prototype. Do not let a technical section omit who will use the result.

## Section audit

For every heading record: section_claim, why_now, evidence_ids, quantified_result, student_contribution, limitation and bridge_to_next.

Use TBD (owner, date) for an open fact. Keep a revision queue ordered by claim risk, not by page order.

## Rewrite pattern

Write each important paragraph as: problem -> user or setting -> intervention -> measured change -> proof -> limitation.

Replace claims such as "internationally leading" or "first" with a comparison table that names the baseline, metric, condition, sample and source. Keep marketing language only after the evidence is visible.

## Track lenses

- Higher-education creative or venture: research depth, innovation, student ownership and industry value.
- Red-tour (青年红色筑梦之旅): participation, field work, beneficiary change, sustainability and the operating mechanism.
- Industry: enterprise question, response fit, demonstrator, implementation and acceptance evidence.
- Vocational or sprout: craft, practice, autonomy, growth and eligibility.

## Deliverables

Return a section map, claim-to-evidence ledger, five highest-risk gaps and a revision queue before drafting full copy. A complete draft may use only facts supplied and verified by the team.
