# GPS agents

Role prompts receive an immutable source packet and return structured artifacts. An adjudicator combines frozen reports only after independent passes.

- `scout` — inventory files and sources.
- `auditor` — verify claims, numbers, IP, finance, and compliance.
- `judge` — score a chosen track against a versioned rubric.
- `architect` — shape project book, deck, and answer logic.
- `coach` — plan drills and owner/date checkpoints.
